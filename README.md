# NHS Foundation Schools Map

Interactive map of the **18 UK Foundation Programme foundation schools**, their locations/subgroups, and major training hospitals.

Source: [UKFPO Foundation Schools](https://foundationprogramme.nhs.uk/programmes/2-year-foundation-programme/ukfp/foundation-schools/)

## Hierarchy

1. **Foundation school** (region)
2. **Subgroup** (e.g. Kent & Medway, South Yorkshire, East region)
3. **City**
4. **Hospitals** with town and trust

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173/

## Stack

Vite · React · TypeScript · Leaflet
